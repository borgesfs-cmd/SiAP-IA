# Dados de referência para testes

`holzinger_swineford_1939.csv` — escores x1–x9 de 301 estudantes (Holzinger & Swineford, 1939),
conjunto clássico de domínio público usado como referência na documentação do lavaan (R) e distribuído
no pacote semopy (licença MIT). Usado apenas para validar a AFC contra resultados publicados do lavaan.
